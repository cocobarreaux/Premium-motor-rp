# Premium Motors RP

Site fictif de concessionnaire automobile destiné au RP.

## Utilisation
Ouvrir `index.html` dans un navigateur.

## Personnalisation
- Modifier le nom/logo directement dans `index.html`.
- Modifier les véhicules dans `script.js`.
- Modifier les couleurs et le design dans `style.css`.
- Les images de démonstration utilisent des URLs externes.

## Mise en ligne
Tu peux déposer les 3 fichiers sur un hébergeur statique compatible avec ton serveur RP.
Le formulaire est actuellement une simulation côté navigateur : aucune donnée n'est réellement envoyée à un serveur.
